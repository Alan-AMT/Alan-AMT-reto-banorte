Trabajé de manera independiente como desarrollador fullstack creando un sistema de punto de venta (POS) a la medida para una tienda de abarrotes local. El objetivo principal del proyecto era digitalizar y centralizar la gestión de productos, ventas, inventario y clientes, brindando mayor control sobre el negocio.

Para construirlo, desarrollé el backend utilizando Python con FastAPI y gestioné los datos con MySQL, mientras que para el frontend utilicé HTML, CSS y JavaScript. Diseñé la arquitectura del sistema con un enfoque modular y escalable para permitir la integración ágil de futuras funcionalidades. Durante el desarrollo, logré integrar exitosamente el software con hardware externo indispensable para el negocio, como escáneres de precios e impresoras de tickets. A nivel de seguridad y operación, implementé un control de acceso basado en roles con vistas protegidas: configuré permisos administrativos y de gestión integral para el dueño de la tienda, y accesos restringidos para los empleados, limitándolos únicamente a las herramientas necesarias para su turno, ya fuera gestión de inventario o exclusivamente la vista de ventas.

Como resultado de esta implementación, la tienda logró optimizar drásticamente sus procesos operativos y de inventario. Esto permitió reducir el tiempo que invertían en tareas administrativas y mejorar la experiencia de compra de los clientes al agilizar el cobro. Además, gracias al control de sistema y los roles de usuario, se redujeron significativamente las mermas y los robos por parte del personal.

El reto de este proyecto freelance era construir una aplicación web desde cero cuyo objetivo principal fuera automatizar y centralizar la gestión de los procesos de certificación ISO del cliente, dándoles un mayor control sobre sus operaciones.

Para lograrlo, me encargué del ciclo completo, comenzando con la toma de requerimientos y llevando a cabo revisiones periódicas con el cliente. Una decisión arquitectónica clave que tomé para acelerar el desarrollo del producto fue desacoplar el frontend mediante servicios mock intercambiables; esto me permitió trabajar en paralelo con el backend y hacer una integración progresiva de las APIs. Como resultado de este desarrollo, BMTS logró automatizar y centralizar exitosamente la gestión de sus certificaciones ISO. Esto se tradujo directamente en una optimización palpable de sus procesos operativos y de auditoría, cumpliendo con el objetivo de brindarles un control total sobre su sistema.
